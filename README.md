# 评测小工具（eval-mini）

给大模型输出做最小可用评测：固定评测集、明确判定规则、可复算的人机一致率。

**状态：进行中。**判定口径已定，评测集与判定脚本正在搭建。

## 要解决什么问题

“模型答得好不好”如果只靠人肉看，结论无法复现，也没法比较两个版本谁更好。

这个仓库把评测拆成三件可量化的事：一份固定的评测集、一套写死的判定规则、一个能算出来的人机一致率。同一批数据，任何人跑都得到同一个分数。

## 进度

- [x] 判定口径：完全正确 / 部分正确 / 错误 / 拒答 四档定义
- [ ] 200 条评测集（含标准答案）
- [ ] 判定脚本：按规则自动打分
- [ ] 人机一致率：人工标注与自动判定的一致比例

## 怎么跑

待评测集与脚本就位后补充。

## 数据从哪来

评测集将覆盖三类典型场景：事实问答、多步推理、边界拒答。每条包含问题、参考答案、判定要点。
